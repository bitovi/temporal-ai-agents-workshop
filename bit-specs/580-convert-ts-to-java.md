# SYSTEMS-580 Convert Typescript Prototypes to Java

## Feature Description

### Part 1 - Lift and shift typescript prototype as typescript
- There exists a typescript implementation of an agentic ai system inside this folder: `/temp-ref-code`
- This task is to move that reference code into the `/5-agent-workflow/typescript` folder
- This coresponds to part/section 5 of the training that this repository is meant for
- As we move this code, we need to modify it so it matches the structure of the previous 4 sections. It should flow seamelessly and be consistent.

### Part 2 - Re-implement the typescript code as java
- Once we have the typescript moved into the `/5-agent-workflow/typescript` folder, we need to port that solution into a java implementation inside `/5-agent-workflow/java`
- Note how this is a pattern followed by the previous 4 sections, having both a typescript and a java implementation
