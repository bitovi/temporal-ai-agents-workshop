# Temporal Java Notes

This repository contains the building blocks of an AI Agent Training with Temporal and Java.

Documentation about different AI technologies and concepts can be found in the `documentation` folder.

Code examples can be found in the `llm-workflows-temporal-java` directory with a README.md for more details.

The `example-langchain` project is very incomplete and the `llm-workflows-temporal-java` is the primary approach.
