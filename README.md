# Temporal AI Agents Workshop Series

## AI Agents Workshop

### Goals

The goal of this workshop is to provide participants with a comprehensive understanding of the principles and practices of building AI agents using Temporal, including prompt engineering, retrieval-augmented generation (RAG), tool calling, and agent workflows.
